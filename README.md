# RealmMesh Mod

面向 Minecraft 1.21.1 / NeoForge 21.1.262 的 Mod，提供中心连接与服务器凭据认证、玩家注册登录、未登录门禁、自助改密、账户变更通知、进离服审计上报和共享物品仓库。

玩家可使用 `/realmmesh register <密码> <确认密码>` 和 `/realmmesh login <密码>`。注册成功自动登录，每次重新进服均需再次登录。

未登录玩家受服务端门禁限制，并按进服时取得的中心配置执行登录超时；默认 60 秒，游戏服每 30 秒刷新配置，仅影响新进入的玩家。已登录玩家可使用 `/realmmesh password <旧密码> <新密码> <确认新密码>`，改密成功后退出并重新登录。共享物品仓库使用游戏内命令，Web 和完整仓库 GUI 不在当前实现范围。当前仅支持 NeoForge；Fabric、Forge 为预留目录。

## 共享物品仓库

已登录玩家可执行 `/realmmesh warehouse list`、`deposit <数量>`、`withdraw <库存ID> <数量>`、`status [操作ID]` 和 `return`。存入读取真实主手，取出只使用主背包 36 格；生存或冒险模式下关闭外部容器并清空鼠标持物后操作。命令不接受替人存取，OP 也不豁免认证。

存入先在游戏服暂扣，中心成功后清理；明确拒绝才归还。取出先检查，中心短事务成功扣库后才整笔给予；空间不足不会部分发放或掉落。未知结果保留操作 ID 和日志供核查，不自动补发、退款或跨重启恢复。具体失败处理和命令见[仓库操作说明](docs/CONFIGURATION.md#共享物品仓库)。

仓库代码通过构建、隔离 JVM 物品/协调状态检查及真实双服双客户端跨服联调，覆盖容量变化和离服退库。改密/重生中的仓库流程、代表性第三方物品及成品 JAR 部署仍待验证。

## 安装与配置

1. 使用 Java 21 和兼容的 NeoForge 服务端或客户端。
2. 在客户端和服务端都将成品 `realmmesh-neoforge-1.21.1-0.1.0-SNAPSHOT.jar` 放入实例的 `mods/`，不要安装 common 或 sources JAR。
3. 首次启动后，在游戏服实例的 `config/realmmesh/connection.toml` 填写中心地址、服务器 ID 与原始密钥。
4. 重启游戏服，在控制台执行 `realmmesh ping`，或由权限等级至少为 2 的玩家执行 `/realmmesh ping`。

服务器 ID 与密钥由中心管理员登记后交付，Mod 不自动注册服务器。配置无效、启动健康通信失败或首次配置拉取失败均会中止游戏服启动。启动前应确保中心可用且凭据有效；首次缺少配置时，可在生成模板后填写并重新启动。
